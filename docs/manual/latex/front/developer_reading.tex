\section*{How to read this book}
\textbf{Foundations} gives the framework in one page and the build and test system. \textbf{Architecture} is the
reference for the driver, the event structures, the stage interfaces with their contracts and the public headers; the
two figures of chapter~\ref{developer_manual-03u5farchitecture} show a whole run and one try of the event loop.
\textbf{Extending and maintaining} adds a new physics model, sink, spectrometer or reaction step by step, explains the
parallel event loop and lists the rules of the code base. The code examples marked with a source file are copies of
compiled and tested files.
