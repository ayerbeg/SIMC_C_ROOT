\chapter*{About this manual}\addcontentsline{toc}{chapter}{About this manual}\markboth{About this manual}{About this manual}\label{developer_manual-index}
This manual is for people who maintain and extend the SIMC++ framework: its architecture,\allowbreak{} data flow, interfaces,
build, tests, plug-ins, parallelism and coding standards. Users who only want to run SIMC++ should read the
user manual\footnote{SIMC++ User Manual, ``SIMC++ user manual'' (\code{docs/\allowbreak{}manual/\allowbreak{}markdown/\allowbreak{}user/\allowbreak{}index.\allowbreak{}md})}. How SIMC++ was translated from the Fortran SIMC and validated against it, with every
Fortran detail, is in the translation report\footnote{From SIMC to SIMC++, ``SIMC Fortran → SIMC++ translation report'' (\code{docs/\allowbreak{}translation/\allowbreak{}markdown/\allowbreak{}index.\allowbreak{}md})}.

\section*{\texorpdfstring{Chapters}{Chapters}}\addcontentsline{toc}{section}{\texorpdfstring{Chapters}{Chapters}}\label{developer_manual-index:chapters}
\begin{enumerate}
\item \hyperref[developer_manual-01u5foverview]{Overview}: what SIMC++ is, the framework in one page, design principles, source layout.
\item \hyperref[developer_manual-02u5fbuild]{Build system and tests}: CMake layout, targets, OBJECT libraries and registration,\allowbreak{} options, CTest
labels, \code{check\_\allowbreak{}all.\allowbreak{}sh}, the installed package.
\item \hyperref[developer_manual-03u5farchitecture]{Architecture and data flow}: driver, event structures, kernels and stages, the registry,
every stage interface with its contract, the order of calls in one try, the normalisation,\allowbreak{} and the
\hyperref[developer_manual-03u5farchitecture:39-public-header-reference]{public header reference}.
\item \hyperref[developer_manual-04u5fextending]{Extending SIMC++}: a new reaction, spectrometer,\allowbreak{} physics model or sink, step by step, with compiled
examples; state and thread-safety rules.
\item \hyperref[developer_manual-05u5fparallel]{Parallelism and performance internals}.
\item \hyperref[developer_manual-06u5fstandards]{Coding standards, commits, technical debt}.
\end{enumerate}

\section*{\texorpdfstring{Conventions of this manual}{Conventions of this manual}}\addcontentsline{toc}{section}{\texorpdfstring{Conventions of this manual}{Conventions of this manual}}\label{developer_manual-index:conventions-of-this-manual}
\begin{itemize}
\item Paths are relative to the SIMC++ source tree \code{SIMC++\_\allowbreak{}Claude/} unless they are absolute.
\item A code block preceded by an HTML comment \code{<!-{}-{}\ from:\ path\ -{}-{}>} is copied verbatim from that file, which is compiled
and tested. The CTest \code{docs\_\allowbreak{}dev\_\allowbreak{}manual} checks that every copy still matches and that every header of \code{include/\allowbreak{}simc}
is described here.
\item When the code and this manual disagree, the code is right: please fix the manual.
\end{itemize}
