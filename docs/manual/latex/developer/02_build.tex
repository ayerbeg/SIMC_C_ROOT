\chapter{\texorpdfstring{Build system}{Build system}}\label{developer_manual-02u5fbuild}
\section{\texorpdfstring{Requirements and a build}{Requirements and a build}}\label{developer_manual-02u5fbuild:21-requirements-and-a-build}
C++20 compiler (gcc 16.2.1 on the reference machine), CMake ≥ 3.15 (≥ 3.29 for the toolchain hint of the L1 tests),
ROOT ≥ 6.40 (components Core, Tree, Hist, RIO), nlohmann/\allowbreak{}json ≥ 3.9 (fetched with FetchContent v3.11.2 when not
installed), Threads, Python 3 (only for the \code{docs} tests), \code{xz} (for the compressed captures of the replay tests).

Without the validation data every test that needs it is skipped (exit 77, "Skipped"); with them, add
\code{-{}DSIMC\_\allowbreak{}REFERENCE\_\allowbreak{}DIR=\allowbreak{}\$SIMC\_\allowbreak{}REFERENCE\ -{}DSIMC\_\allowbreak{}FORTRAN\_\allowbreak{}DIR=\allowbreak{}\$SIMC\_\allowbreak{}FORTRAN\ -{}DSIMC\_\allowbreak{}BASELINE\_\allowbreak{}DIR=\allowbreak{}\$SIMC\_\allowbreak{}BASELINES} (or export
\code{SIMC\_\allowbreak{}REFERENCE}, \code{SIMC\_\allowbreak{}FORTRAN}, \code{SIMC\_\allowbreak{}BASELINES} before the first configure: they are the defaults).

Flags: \code{-{}Wall\ -{}Wextra\ -{}pedantic} everywhere (the build has 0 warnings; keep it so), Release \code{-{}O3\ -{}DNDEBUG}. \textbf{Do not
add \code{-{}march=\allowbreak{}native}, \code{-{}ffast-{}math} or \code{-{}ffp-{}contract=\allowbreak{}fast}}: FMA contraction and value-unsafe optimisations change the
floating-point results and break every bitwise reference test (the numerical rules are in the
translation report\footnote{From SIMC to SIMC++, ``4. Numerical conventions'' (\code{docs/\allowbreak{}translation/\allowbreak{}markdown/\allowbreak{}04\_\allowbreak{}numerics.\allowbreak{}md})}).

The comparison tool \code{simc\_\allowbreak{}compare} is a separate CMake project in \code{validation/} (its own build directory and CTest
suite; the statistics are documented in validation/\allowbreak{}README.md\footnote{\code{validation/\allowbreak{}README.\allowbreak{}md}}).

\section{\texorpdfstring{OBJECT libraries and registration}{OBJECT libraries and registration}}\label{developer_manual-02u5fbuild:23-object-libraries-and-registration}
Plug-ins register themselves by name during static initialisation (\code{SIMC\_\allowbreak{}REGISTER}\simcidx{SIMC_REGISTER@\code{SIMC\_REGISTER}}, core/\allowbreak{}Registry.\allowbreak{}h,\allowbreak{} chapter 3). The
linker drops an object file of a static archive that nothing references, so \textbf{every library that contains a
\code{SIMC\_\allowbreak{}REGISTER}\simcidx{SIMC_REGISTER@\code{SIMC\_REGISTER}} line is an OBJECT library} and is linked directly by the executable. The exception is
\code{simcfw\_\allowbreak{}random} (STATIC): \code{Simc\allowbreak{}Run::\allowbreak{}initialise}\simcidx{Classes and interfaces!SimcRun@\code{SimcRun}} constructs \code{Mt64Random}\simcidx{Classes and interfaces!Mt64Random@\code{Mt64Random}} / \code{RanluxRandom}\simcidx{Classes and interfaces!RanluxRandom@\code{RanluxRandom}} directly when the registry
does not contain them, which pulls their object files (and so their registrations) in (SimcRun.\allowbreak{}cpp l.127-139).

The objects of an OBJECT library reach only targets that link it \emph{directly}. The INTERFACE target \code{simc} therefore
passes them explicitly as \code{INTERFACE\_\allowbreak{}SOURCES} (\code{\$<TARGET\_\allowbreak{}OBJECTS:\allowbreak{}.\allowbreak{}.\allowbreak{}.\allowbreak{}>}), in the build tree and in the installed package
(top-level CMakeLists.\allowbreak{}txt,\allowbreak{} "Installation"). This is what lets an out-of-tree executable that links \code{SIMC::\allowbreak{}simc} get
every built-in stage without whole-archive flags.

A new module: add \code{src/\allowbreak{}<module>\allowbreak{}/\allowbreak{}CMake\allowbreak{}Lists.\allowbreak{}txt} with an OBJECT library if it registers plug-ins (STATIC otherwise),
\code{add\_\allowbreak{}subdirectory} it in the top-level file, and append it to \code{SIMC\_\allowbreak{}DRIVER\_\allowbreak{}LIBS} (chapter 4).

\section{\texorpdfstring{\code{tools/\allowbreak{}check\_\allowbreak{}all.\allowbreak{}sh}}{tools/\allowbreak{}check\_\allowbreak{}all.\allowbreak{}sh}}\label{developer_manual-02u5fbuild:26-toolschecku5fallsh}
The acceptance check of every change: a clean build of everything plus both test suites, logged.

\begin{simcshell}[basicstyle=\ttfamily\scriptsize]
TMPDIR=<large scratch dir> ROOTSYS=<ROOT install> tools/check_all.sh --commit <hash> --label <task>
\end{simcshell}
\begin{itemize}
\item Paths: ROOT from \code{\$ROOTSYS} (else \code{root-{}config\ -{}-{}prefix}); the validation data from the environment variables
\code{SIMC\_\allowbreak{}REFERENCE}, \code{SIMC\_\allowbreak{}FORTRAN}, \code{SIMC\_\allowbreak{}BASELINES}, or, for those not set, from the untracked file \code{check\_\allowbreak{}all.\allowbreak{}env} in
the project directory (the parent of the source tree; shell syntax, one \code{NAME=\allowbreak{}path} per line). Nothing machine-specific
is committed. Without the data check\_all still runs, with those tests skipped; \code{git.\allowbreak{}txt} records which data were used.
\item \code{-{}-{}commit\ REV} builds a clean detached worktree of REV (use it whenever other agents have uncommitted work).
\item It takes the same lock as \code{run\_\allowbreak{}simc.\allowbreak{}sh} (\code{simc\_\allowbreak{}runs/\allowbreak{}.\allowbreak{}lock}), so runs are serialised; check \code{ps} first.
\item It writes \code{SIMC++\_\allowbreak{}Project/\allowbreak{}simc\_\allowbreak{}runs/\allowbreak{}<timestamp>\allowbreak{}\_\allowbreak{}check\_\allowbreak{}<label>\allowbreak{}/} (summary.\allowbreak{}md,\allowbreak{} git.txt with the toolchain
fingerprint,\allowbreak{} build.log, tests.log, val\_\allowbreak{}build.\allowbreak{}log,\allowbreak{} val\_\allowbreak{}tests.\allowbreak{}log),\allowbreak{} removes the build trees, and appends one line to
\code{simc\_\allowbreak{}runs/\allowbreak{}index.\allowbreak{}tsv}: \code{run\_\allowbreak{}id\ overall\ build\ run\ tests\ seconds\ config} (\code{build} and \code{tests} are
\code{<main>\allowbreak{}/\allowbreak{}<validation>} exit codes; config \code{check\_\allowbreak{}all@<commit>}). The exit code is 0 only if both builds and both
suites pass. It runs every test including \code{slow} (about one hour with all validation data).
\item Use a \code{TMPDIR} on a large disk (the worktree and the build trees are created there).
\end{itemize}
\section{\texorpdfstring{The installed package}{The installed package}}\label{developer_manual-02u5fbuild:27-the-installed-package}
\begin{simcshell}[basicstyle=\ttfamily\footnotesize]
cmake --install build --prefix $HOME/simc
\end{simcshell}
installs \code{bin/} (\code{simc++}, \code{inp2json}, \code{hist2json}, \code{simc\_\allowbreak{}root\_\allowbreak{}identity}), \code{include/\allowbreak{}simc} (the public headers,
\textbf{without} the \code{kernel/} directories),\allowbreak{} \code{lib/\allowbreak{}simc} (static libraries) and \code{lib/\allowbreak{}simc/\allowbreak{}objects} (the objects of the
OBJECT libraries), \code{lib/\allowbreak{}cmake/\allowbreak{}SIMC} (\code{SIMCConfig.\allowbreak{}cmake}, \code{SIMCConfig\allowbreak{}Version.\allowbreak{}cmake}, \code{SIMCTargets.\allowbreak{}cmake}),
\code{share/\allowbreak{}simc/\allowbreak{}data} (COSY maps, tables, spectral functions, field map), \code{share/\allowbreak{}simc/\allowbreak{}docs}, \code{share/\allowbreak{}simc/\allowbreak{}examples}, and
\code{share/\allowbreak{}simc/\allowbreak{}cmake/\allowbreak{}Simc\allowbreak{}Installed\allowbreak{}Data\allowbreak{}Root.\allowbreak{}cpp}.

\code{find\_\allowbreak{}package(\allowbreak{}SIMC\ 2.\allowbreak{}0)} (version compatibility \code{SameMajorVersion}) finds ROOT 6.40, nlohmann\_\allowbreak{}json and Threads, and
provides \code{SIMC::\allowbreak{}simc} and \code{SIMC\_\allowbreak{}DATA\_\allowbreak{}DIR}. \code{SIMCConfig.\allowbreak{}cmake} adds the interface source \code{Simc\allowbreak{}Installed\allowbreak{}Data\allowbreak{}Root.\allowbreak{}cpp}
to \code{SIMC::\allowbreak{}simc}, compiled into the consumer with \code{SIMC\_\allowbreak{}INSTALLED\_\allowbreak{}DATA\_\allowbreak{}DIR=\allowbreak{}<prefix>\allowbreak{}/\allowbreak{}share/\allowbreak{}simc/\allowbreak{}data}: it registers the
package's data directory at start-up (\code{simc::\allowbreak{}detail::\allowbreak{}Set\allowbreak{}Installed\allowbreak{}Data\allowbreak{}Root}), so a consumer program finds the installed
data without \code{-{}-{}data-{}dir}\simcidx{Command-line options!data-dir@\code{-{}-{}data-{}dir}}. The CTest \code{package\_\allowbreak{}out\_\allowbreak{}of\_\allowbreak{}tree\_\allowbreak{}plugin}
(\code{examples/\allowbreak{}out\_\allowbreak{}of\_\allowbreak{}tree\_\allowbreak{}plugin/\allowbreak{}package\_\allowbreak{}check.\allowbreak{}sh}) proves the whole chain on every \code{check\_\allowbreak{}all}.


\section{Documentation targets}\label{developer_manual-02u5fbuild:28-documentation-targets}

\begin{itemize}
\item \code{doc} (needs doxygen; graphviz \code{dot} for the graphs): the API reference as HTML, \code{<build>/docs/doxygen/html/index.html} --- open it in a browser.
\item \code{doc\_pdf} (doxygen, pdflatex and the TeX packages listed in \code{docs/README.md}): \code{<build>/docs/doxygen/SIMCpp\_API\_Reference.pdf}.
\item \code{pdf} (xelatex, makeindex): the three books in \code{<build>/docs/}.
\end{itemize}

\begin{lstlisting}[language=bash]
cmake --build $SIMCPP_BUILD --target doc      # HTML API reference
cmake --build $SIMCPP_BUILD --target doc_pdf  # API reference as PDF
cmake --build $SIMCPP_BUILD --target pdf      # user manual, developer manual, translation report
\end{lstlisting}

If doxygen is not installed, \code{doc} only prints a message. The HTML is not committed; the PDFs in \code{docs/*/pdf/} are release copies to rebuild and re-commit when the sources change.
