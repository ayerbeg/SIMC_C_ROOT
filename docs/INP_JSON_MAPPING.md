# .inp → JSON mapping (D-003)

Generated by `inp2json --mapping` from `ParameterTable()` (src/core/SimcParameters.cpp). Do not edit by hand.

- One row for each of the 106 variables registered in `dbase.f:regallvars`. A completeness test
  (`params_completeness`) checks the list, the storage kinds and the defaults against
  `reference/functions/_inputs/inp_variables.csv`.
- JSON config: `{"parameters": {...}}`. The path is the Fortran name split on `%`. Keys are matched
  case-insensitively, like CTP. Unknown keys produce a warning, and keys starting with `_` are ignored.
- Values keep the **.inp units**. The conversions dbase.f applies (deg→rad, mrad→rad, mg→g, % of Ebeam→MeV, …)
  happen later in RunSetup. `inp2json --table` prints them.
- Defaults are the true Fortran defaults. They are zero/blank, except SPedge and cuts%Em (±1e10, from init.f:min_max_init).
- The obsolete `.` names (`targ.A`, `spec.e.P`, …) are **not** mapped. Like the Fortran, `inp2json` reports
  them as "not registered" and ignores their values (D-005).

| — | `--data-dir DIR` | `data/spectral` | directory of the Fortran working-directory data files (theory and Benhar files) |
