\chapter{\texorpdfstring{Following upstream SIMC}{Following upstream SIMC}}\label{translation_report-07u5ffollowingu5fupstream}
\simcabstract{SIMC++ follows the official Fortran SIMC, \href{https://github.com/JeffersonLab/simc_gfortran}{JeffersonLab/\allowbreak{}simc\_\allowbreak{}gfortran}.
The file \code{UPSTREAM\_\allowbreak{}SIMC} at the top of the source tree records the upstream commit that \code{-{}-{}fortran-{}compat}\simcidx{Command-line options!fortran-compat@\code{-{}-{}fortran-{}compat}} reproduces,
together with the deliberate exceptions. The translation itself (chapters 1-6) was made and proved against commit
294f662 (2026-01-16). This chapter describes the first update, to commit 59ccdf6 (2026-10-01; decisions D-080 to
D-082), and the procedure for the next updates.}
\section{\texorpdfstring{The update 294f662 → 59ccdf6}{The update 294f662 → 59ccdf6}}\label{translation_report-07u5ffollowingu5fupstream:71-the-update-294f662--59ccdf6}
Upstream added 27 commits between the two versions (D-080). The Fortran impact analysis (\code{reference/\allowbreak{}U.\allowbreak{}F1\_\allowbreak{}report.\allowbreak{}md}) built the
new version in a separate checkout (\code{simc\_\allowbreak{}gfortran\_\allowbreak{}upstream}), ran it on the existing inputs and on new ones, and
classified each commit. The frozen tree \code{simc\_\allowbreak{}gfortran} stays at 294f662: all the references of chapters 1-6 depend on
it.

\subsection*{\texorpdfstring{What changed in SIMC++}{What changed in SIMC++}}\label{translation_report-07u5ffollowingu5fupstream:what-changed-in-simc}
\begin{itemize}
\item \textbf{U.1}: the Cu-64 spectral function, the nuclear-elastic reaction (\code{doing\_\allowbreak{}nuc\_\allowbreak{}elast}\simcidx{Parameters!doing_nuc_elast@\code{doing\_nuc\_elast}}, user manual chapter 5), the
\code{.\allowbreak{}hist} line, z/pt² for every reaction, the SIDIS z > 1 warning, pfermi = 0 instead of NaN in both modes.
\item \textbf{U.2}: the 59ccdf6 tree layout is the default; \code{-{}-{}tree-{}layout\ legacy}\simcidx{Command-line options!tree-layout@\code{-{}-{}tree-{}layout}} (JSON \code{"output":\ \{"layout":\ "legacy"\}}) writes
the 294f662 layout (user manual chapter 7).
\item \textbf{U.R}: \code{-{}-{}fortran-{}compat}\simcidx{Command-line options!fortran-compat@\code{-{}-{}fortran-{}compat}} now reproduces 59ccdf6 (\code{UPSTREAM\_\allowbreak{}SIMC}). The option \code{-{}-{}compat-{}target\ 294f662}\simcidx{Command-line options!compat-target@\code{-{}-{}compat-{}target}} (JSON
\code{"run":\ \{"compat\_\allowbreak{}target":\ "294f662"\}}) keeps the old behaviour of the two findings that upstream fixed, so the
references of the frozen tree can still be reproduced bit for bit. The test harnesses choose the target from the
reference: a \code{.\allowbreak{}hist} with the line \code{doing\_\allowbreak{}nuc\_\allowbreak{}elast=} is a 59ccdf6 reference, otherwise 294f662
(\code{tests/\allowbreak{}l1/\allowbreak{}ranlux\_\allowbreak{}fullrun.\allowbreak{}sh}, \code{validation/\allowbreak{}scripts/\allowbreak{}p15\_\allowbreak{}shipped\_\allowbreak{}regression.\allowbreak{}sh}); the compat regression baselines are
in the 294f662 behaviour (\code{tests/\allowbreak{}regression/\allowbreak{}output\_\allowbreak{}identity.\allowbreak{}sh} adds \code{-{}-{}compat-{}target\ 294f662}\simcidx{Command-line options!compat-target@\code{-{}-{}compat-{}target}}).
\end{itemize}

\subsection*{\texorpdfstring{Exceptions: where \code{-{}-{}fortran-{}compat} does not reproduce 59ccdf6}{Exceptions: where -{}-fortran-compat does not reproduce 59ccdf6}}\label{translation_report-07u5ffollowingu5fupstream:exceptions-where---fortran-compat-does-not-reproduce-59ccdf6}
\begin{itemize}
\item \textbf{U-A1 nuclear elastic}: SIMC++ keeps the complete 20d46fc code (the 59ccdf6 code never produces an event). Reference:
\code{reference/\allowbreak{}runs/\allowbreak{}up\_\allowbreak{}ee\_\allowbreak{}calcium48\_\allowbreak{}20d46fc}.
\item \textbf{U-A2, U-A4}: no STOP and no overflow; SIMC++ writes the tree.
\item \textbf{U-A3 pion 1/Z}: the 294f662 weight for A ≥ 3, which\_pion 2/3 (the runs \code{up\_\allowbreak{}upf1\_\allowbreak{}pion\_\allowbreak{}c12\_\allowbreak{}wp\{2,\allowbreak{}3\}\_\allowbreak{}A} differ by the
factor 1/6 for C-12 and are not identity tests).
\end{itemize}
\subsection*{\texorpdfstring{Validation of the compat target}{Validation of the compat target}}\label{translation_report-07u5ffollowingu5fupstream:validation-of-the-compat-target}

\code{.\allowbreak{}hist} (except the time lines), \code{.\allowbreak{}geni}, \code{.\allowbreak{}gen} text-identical and the whole tree bitwise identical. U.R added
\code{up\_\allowbreak{}upf1\_\allowbreak{}pion\_\allowbreak{}h\_\allowbreak{}wp3\_\allowbreak{}A} (H(e,\allowbreak{}e'π−)Δ++,\allowbreak{} which 294f662 STOPs) and \code{up\_\allowbreak{}upf1\_\allowbreak{}kaon\_\allowbreak{}h\_\allowbreak{}k1\_\allowbreak{}rad\_\allowbreak{}dec1\_\allowbreak{}nontu} (kaon decay in
flight, Nntu = 0 because of U-A2: \code{.\allowbreak{}hist}/\code{.\allowbreak{}geni}/\code{.\allowbreak{}gen} only). The 294f662 references keep passing with
\code{-{}-{}compat-{}target\ 294f662}\simcidx{Command-line options!compat-target@\code{-{}-{}compat-{}target}}.

\section{\texorpdfstring{How to follow the next upstream changes}{How to follow the next upstream changes}}\label{translation_report-07u5ffollowingu5fupstream:72-how-to-follow-the-next-upstream-changes}
\begin{enumerate}
\item \textbf{Check.} \code{tools/\allowbreak{}check\_\allowbreak{}upstream\_\allowbreak{}simc.\allowbreak{}sh} lists the upstream commits after the one in \code{UPSTREAM\_\allowbreak{}SIMC} and the files
they touch ("Up to date." when there are none).
\item \textbf{Fortran impact analysis} (fortran-reference): update the upstream checkout, build it, run the existing inputs with
the old and the new binary, and classify each commit: no effect, new feature, changed behaviour, fix of a known
finding, new finding. Produce the references (\code{reference/\allowbreak{}runs/\allowbreak{}up\_\allowbreak{}*}, L1 tables) and a report like
\code{reference/\allowbreak{}U.\allowbreak{}F1\_\allowbreak{}report.\allowbreak{}md}.
\item \textbf{Port} (one coherent group per task): follow the new Fortran; keep the corrections of the catalogue. Upstream fixes
of known findings: mark the finding "fixed upstream in \&lt;commit\&gt;" (D-081) and make \code{-{}-{}fortran-{}compat}\simcidx{Command-line options!fortran-compat@\code{-{}-{}fortran-{}compat}} follow the fix,
keeping the old behaviour behind \code{-{}-{}compat-{}target}\simcidx{Command-line options!compat-target@\code{-{}-{}compat-{}target}} when old references need it. New upstream bugs: new findings in
FORTRAN\_\allowbreak{}DIFFERENCES.md (\code{U-{}*}), reported upstream.
\item \textbf{Validate}: RANLUX full-run identity against the new references, L1 tables, the regression baselines (regenerate
them only when the change is proved), \code{ctest\ -{}L\ docs}, \code{tools/\allowbreak{}check\_\allowbreak{}all.\allowbreak{}sh}.
\item \textbf{Record}: update \code{UPSTREAM\_\allowbreak{}SIMC} (full sha, date, the exceptions); \code{tools/\allowbreak{}check\_\allowbreak{}upstream\_\allowbreak{}simc.\allowbreak{}sh} must then report
0 newer commits. Update this chapter, the catalogue and the manuals (both editions) and rebuild the PDFs.
\end{enumerate}
